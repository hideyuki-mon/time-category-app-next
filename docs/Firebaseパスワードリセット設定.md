# パスワードリセットメールが届かない場合の確認手順

パスワードリセットメールが届かない場合、以下の Firebase Console 設定を確認してください。

## 1. 認証されたドメインの追加（必須）

Firebase は、パスワードリセットのリクエストが「認証されたドメイン」から送信された場合のみメールを送信します。

### 手順

1. [Firebase Console](https://console.firebase.google.com/) を開く
2. プロジェクトを選択
3. **認証（Authentication）** → **設定** タブ → **認証されたドメイン**
4. **ドメインを追加** をクリック
5. 以下のドメインを追加：
   - `time-category-app-next.vercel.app`（本番）
   - `localhost`（ローカル開発用・通常は既に登録済み）

> ⚠️ Vercel のプレビューデプロイ用に `*.vercel.app` を追加したい場合、Firebase はワイルドカードをサポートしていないため、使用するサブドメインを個別に追加してください。

## 2. メール/パスワード認証の有効化

1. **認証** → **Sign-in method** タブ
2. **メール/パスワード** をクリック
3. **有効にする** をオンにする
4. **保存**

## 3. メールテンプレートの確認（任意）

1. **認証** → **テンプレート** タブ
2. **パスワードをリセット** をクリック
3. 送信元メールアドレスが正しく設定されているか確認
4. 必要に応じて件名や本文をカスタマイズ可能

## 4. その他の確認事項

- **迷惑メールフォルダ** を確認する
- **メールアドレスがメール/パスワードで登録されているか** 確認する（Google のみで登録したアカウントにはパスワードリセットは送信されません）
- **数分待つ**（メールの配信に時間がかかることがあります）
- **Gmail の場合**：プロモーションタブやソーシャルタブも確認する

## 5. エラーメッセージの意味

| 表示メッセージ | 原因 |
|---------------|------|
| このメールアドレスは登録されていません | そのメールアドレスでアカウントが作成されていない |
| このアカウントはGoogleで登録されています | メール/パスワードではなく Google で登録したアカウント |
| このドメインは認証されていません | Firebase Console の「認証されたドメイン」にアプリのドメインを追加する必要がある |
