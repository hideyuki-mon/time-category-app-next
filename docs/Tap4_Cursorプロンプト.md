# Tap4 PWAアプリ — プロジェクト一括生成

以下の仕様に従って、Tap4というPWA時間管理アプリのプロジェクトを一括で作成してください。

## プロジェクト概要

1日の時間を4カテゴリ（ただの消費 / 生産につながる消費 / 生産 / 思考停止ルーティーン）に分けて記録するストップウォッチ型PWAアプリ。

## 4カテゴリの定義（全ファイル共通）

| ID | 名前 | カラー | 薄色（背景用） |
|----|------|--------|----------------|
| 0 | ただの消費 | #E74C3C | rgba(231,76,60,0.15) |
| 1 | 生産につながる消費 | #F39C12 | rgba(243,156,18,0.15) |
| 2 | 生産 | #27AE60 | rgba(39,174,96,0.15) |
| 3 | 思考停止ルーティーン | #3498DB | rgba(52,152,219,0.15) |

## カラーテーマ（ダークテーマ）

- 背景: `#1a1a22`
- サーフェス: `#24242e`
- ボーダー: `#3a3a46`
- テキスト: `#e8e8f0`
- テキスト薄: `#8888a0`

## 重要な実装ルール

1. **計測切り替え**: 別カテゴリをタップしたら、現在の計測を即停止→保存→新カテゴリ開始（ワンタップで切り替え）
2. **タブ切り替え時も計測継続**: タブを移動しても計測は止まらない
3. **tabular-nums**: 数字表示には全て`fontVariantNumeric: 'tabular-nums'`を適用
4. **safe area**: タブバーにsafe-area-inset-bottomを適用（ノッチ端末対応）
5. **日付変更対応**: 復元時にdateが今日と異なれば、前日23:59:59までの記録を保存してリセット

※本プロジェクトは Next.js を使用。上記仕様の設計思想を参考に実装する。
